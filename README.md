# Bridge Deterioration Prediction Using Survival Analysis

## Project Overview

This ENGG2112 project predicts the time until bridges deteriorate from Good condition to Fair or Poor using survival analysis.

The project uses annual US National Bridge Inventory (NBI) data from 1992 to 2025.

## Models

The project compares the following survival analysis models:

- Age-only Cox Proportional Hazards model
- Multivariable Cox Proportional Hazards model
- Weibull Accelerated Failure Time model
- Random Survival Forest
- Improved Weibull and Random Survival Forest models

## Repository Structure

- `bridge_time_primary_notebooks/notebooks/` contains the 10 final Jupyter notebooks.
- `data/processed/` contains the cleaned annual NBI datasets.
- `data/final/` contains the final survival analysis datasets.
- `src/` contains data preparation scripts.
- `results/` contains supporting results and outputs.
- `requirements.txt` contains the Python dependencies.

## Installation

Python 3.13.3 was used during development.

Clone the repository and open a terminal in the main project folder.

Create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install the required packages:

```bash
python -m pip install -r requirements.txt
```

Start Jupyter Notebook:

```bash
python -m notebook
```

## Notebook Execution Order

1. `01_data_preparation.ipynb` - Data preparation
2. `02_train_test_split.ipynb` - Train and test split
3. `03_weibull_time.ipynb` - Weibull AFT model
4. `04_cox_age_only.ipynb` - Age-only Cox model
5. `05_cox_multivariable_time.ipynb` - Multivariable Cox model
6. `06_rsf_time.ipynb` - Random Survival Forest
7. `07_model_improvements.ipynb` - Model improvements
8. `08_deterioration_factors.ipynb` - Deterioration factor analysis
9. `09_time_prediction_evaluation.ipynb` - Model evaluation
10. `10_rsf_weibull_improvements.ipynb` - Further model improvements

The notebooks are located in `bridge_time_primary_notebooks/notebooks/`.

## Data

The repository includes cleaned annual NBI datasets and final survival datasets.

Notebook 01 requires the original raw NBI files, which are not included due to their size.

The supplied datasets allow the modelling notebooks to be run without repeating the initial data cleaning.

## Reproducing Results

Launch Jupyter from the repository root.

Run the modelling notebooks before Notebook 09, as the evaluation notebook requires prediction CSV files generated by earlier notebooks.

Model training times depend on available hardware.

The execution instructions have not yet been verified through a complete fresh-environment run.

## Evaluation

The models are evaluated using the concordance index (C-index), which measures how well they rank bridge deterioration times.

The analysis also investigates how bridge characteristics and structural condition ratings influence deterioration predictions.
